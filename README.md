# enenhz.github.io

个人落地页项目，展示 `enen`（三角洲解密创始人）与社群影响力。

## 项目亮点

- 黑客风 UI（终端窗口、霓虹配色、扫描线质感）
- 首屏打字机动画（`enen@delta:~` 与标题逐字输出）
- 标题中 `enen` 实时特效高亮（从首字母 `e` 开始）
- 响应式布局，移动端可用
- 基础 SEO 优化（Meta、Open Graph、Twitter、结构化数据）
